承接：M1 s1 用「只看邊緣寬度」的一階估計，得到允許的 skew 約 18.7 ps。M1 s2、s3 完成兩種校正：消光比 25.8 dB 的殘留已由重新求相位吸收，輸入相位由 heater 持續追蹤。本步在校正後的條件下驗收時序：消光比用 M1 s2 的規格與重新求的相位，相位假設已在容許範圍內。

本步要回答：輸入每 100 ps 換一組時，轉態期間的干涉、接收端的頻寬、各路的 skew 與「0」的殘留光，實際占去多少可取樣的時間？一階估計準不準？

交給下一步：window.json（每個函數在不同 skew 下的功率代價）與 skew 代價曲線：skew 額外造成的代價達 1 dB 的點最小約 18 ps（OR4）。M1 s5 與論文 M2 s2 由此訂時間對齊規格（≤ 15 ps，留 3 ps 餘裕）。M1 s5 把它整合進介面規格與總功率預算。

名詞對照：功率代價（power penalty：為了在取樣窗內維持和靜態時一樣的判讀餘裕，要多給的光功率，以 dB 表示）、符號（一個 UI 內 4 路輸入的一組值，共 16 種）、升餘弦（以餘弦曲線平滑變化的轉態形狀）、眼圖（把每個符號的波形疊在同一時間軸上的圖，中間張開的區域就是可取樣的範圍）、延遲角落（各路延遲只取範圍兩端的組合）。

① 問題與範例

學習目標：能用時域模型算出干涉電路的取樣窗；能用功率代價把「時間不夠」換成「要多給多少光」；能比較一階估計與完整模型的差別。

類比：拍一張五個人同時跳起的合照。每個人起跳、落地都需要時間（轉態），相機快門也需要一點時間（取樣），若有人慢半拍（skew），能拍到「五個人都在空中」的時間就變短。一階估計是直接把這些時間相減；完整計算則要看每一種跳法的組合，因為 B7 的判讀是各路光干涉的結果，某一路正在轉態時，會影響其他路的判讀。

② 原理與推導

1. 時域模型

每路輸入的光場在「0」與「1」之間以升餘弦轉態，10–90% 時間 ttx＝30 ps，並延遲 τj：

xj(t)=a0eiψ+(1−a0eiψ)bj(t−τj),y(t)=Ux(t)

bj(t) 是第 j 路的開關波形（0 到 1），a0、ψ 是 M1 s2 的殘留光。y＝Ux 是靜態時的寫法；高速時要把晶片內各條路徑的延遲也放進去（下面第 3 點）。判讀量 ΔP(t)＝|y2|²−|y4|² 經接收端濾波（二階 Butterworth，7 GHz）。注意 ΔP 是光場的二次式（課程 M1 s3）：一路正在轉態時，它和參考光、和其他路的干涉項同時在變，這是一階估計沒有算到的部分。

2. 動態 margin 與功率代價

在取樣時間 t（從符號起點算），把所有符號中最差的判讀量記為動態 margin：

m(t)=minkskΔP濾波後(kUI+t),mwin=maxt0mint∈[t0,t0+Treq]m(t)

mwin 是把取樣需要的 Treq＝23 ps 放在最好的位置時，窗內最差的 margin。離散計算時窗的兩個端點都要算：0.5 ps 格點下 23 ps 窗含 47 個格點，所有可行的起點都要搜尋。判讀量與光功率成正比，所以要讓取樣窗內的 margin 回到靜態 margin m0 的水準，光功率要多給 10 log10(m0／mwin) dB，這就是功率代價。它直接接到 M1 s1 的功率預算，不需要再假設雜訊門檻。

3. 路徑層級的延遲

每個輸出是多條路徑的光加起來，各路徑經過的 MZI 數目不同，延遲也不同：

yk(t)=rk+∑j∑pwkjpxj(t−Δtkjp)

p 是從輸入 j 到輸出 k 的第 p 條路徑，wkjp 是它的複數權重，Δtkjp 是它的相對延遲，rk 是參考光的貢獻。實作上不必列出每條路徑：讓光場逐欄傳過 B7，同一欄裡走 MZI 的兩條軌先經 2×2 矩陣混合，再比直通多延遲一段（課程 M3 s1 的 11.72 µm，約 0.167 ps），扇入、扇出依課程 M3 s3 的長度延遲；共同延遲不影響判讀，都扣掉。輸入不變時，逐欄傳遞的結果要等於 U，程式自動核對（誤差 2e-16）。載波相位不另外加，假設已由校正（M1 s3）對好，這裡只看包絡延遲（包絡是資料開關造成的振幅變化，不含光波本身的快速振盪）。

4. 資料序列與 skew 的取法

資料用 16 種輸入的 de Bruijn 序列 B(16, 3)（B(k, n) 表示 k 種符號、每一種長度 n 的組合都恰好出現一次的循環序列；這裡 16³＝4096 個符號），涵蓋所有一次轉態與前一個符號的影響。skew 範圍 S 內，會影響判讀的輸入各取延遲 0 或 S（四輸入函數 16 種、二輸入函數 4 種組合），取最差者。

兩項數值檢查：(a) 格點由 0.5 ps 縮為 0.25 ps，代價最大的情況（OR4、skew 20 ps）只差 −0.01 dB；(b) 功率代價由 margin 比值換算，前提是雜訊不隨光功率改變；M1 s1 的雜訊組成中熱雜訊加比較器雜訊占 99%，前提成立。若 shot noise 或 RIN 變成主要雜訊，這個換算會低估代價。

⑤ 常見錯誤與自我檢查

  • 只在每個符號自己的 UI 內找取樣點：接收端濾波有延遲，眼圖可能跨到下一個符號的時間範圍；要從符號起點往後找超過一個 UI。本步第一次就犯了這個錯。
  • 以為 skew 0 就沒有代價：轉態與接收端頻寬本身就會讓取樣窗內的 margin 小於靜態值。
  • 只試一種延遲組合：干涉判讀的最差情況和「哪幾路晚到」有關，要取多個組合中最差的。
自我檢查 1：為什麼四輸入函數的代價比二輸入大？

四輸入函數有 4 路資料同時參與干涉，任一路轉態都會改變判讀量；二輸入函數只有 x1、x2 進判讀埠。四輸入函數的動態 margin 頂端最窄（圖 M1-7），取樣需要的 23 ps 放進去時，邊緣的 margin 已經下降較多。

自我檢查 2：功率代價 2 dB 是什麼意思？要怎麼補？

取樣窗內最差的判讀量只有靜態時的 10−0.2≈63%。判讀量與光功率成正比，所以光功率要多給 2 dB（約 1.6 倍）才能維持和靜態時同樣的錯誤率。M1 s1 的功率預算要把這 2 dB 算進去。

自我檢查 3：一階估計 18.7 ps 和 1 dB 代價點 18.0 ps 很接近，是不是以後只用一階估計就好？

不行。兩者的準則不同：一階估計是「skew 用光邊緣以外的餘裕」，完整模型是「skew 額外造成多少代價」，1 dB 是選定的門檻；換成 0.5 或 2 dB，點就移到約 12 或 26 ps。一階估計只能當量級的快速檢查，它也算不出 skew 0 時的代價與四輸入函數在大 skew 時的急速惡化。
