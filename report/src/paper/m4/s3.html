承接：M4 s2 交出葉盒下界 V̲s、盒內護欄上界 Γ̄ 與連續時間的 Ein、Ebtw，並以 41 個盒內抽樣點驗證下界不超過模擬值；M3 s3 交出同一延遲盒的詳細模擬窗寬（對齊 50／54／66 ps，盒內 41 點最小 37／40.5／53 ps）。

本步要回答：整個 13.2 ps 盒（每路 ±6.6 ps 的每一組延遲）、宣告的情境序列與全部資料歷史下，AND4、MAJ4、XOR2 的共同取樣窗至少多寬（草稿式 9、命題 1、表 III 認證欄）？夠不夠 Treq＝23 ps？

交給下一步：cert.json（各函數、各種葉盒數與資料歷史下的認證窗、起訖相位、每側餘裕與計算時間）。M4 s4 用認證窗與每側餘裕做 UI 預算，並檢查接收端頻寬與位元率改變時窗是否仍夠。

名詞對照：認證窗（certified window）＝下界扣掉護欄上界與連續時間誤差後，在整個延遲盒內都安全的最長共同取樣區間，是保證值；每側餘裕（slack per side）＝取樣時刻放在認證窗中點時，窗的每一側比 Treq 所需多出的時間，(Wcert − Treq)/2；單葉＝不切，把整個延遲盒當成 1 個葉盒；多葉（切細）＝每路切 2 份或更多；資料歷史＝目前符號之前的輸入序列，經接收端的記憶影響現在的判讀量。

① 問題與範例

接續 M4 s2 的橋梁比喻：s2 證明了「10 到 12 噸之間的每一台車，橋的應力都不超過某條曲線」；本步要讀出這條曲線在哪一段時間內仍低於安全線，而且這段時間是否長到足以讓車子通過。對晶片來說，下界曲線減去護欄上界之後仍 ≥ 0 的最長區間，就是盒內任何一組延遲都能安全取樣的時間，稱為認證窗。M3 s3 的 41 個點只能說「這 41 組延遲的窗至少 37 ps」；認證窗則對盒內無限多組延遲都成立，所以它一定不大於任何抽樣結果。

還有一個 M4 s2 沒處理的問題：s2 的下界只涵蓋宣告的情境序列（Euler 序列＋768 個隨機符號）。接收端有記憶，判讀量受前幾個符號影響，序列裡沒出現過的符號組合可能更差。本步用 de Bruijn 序列涵蓋所有 n 個符號的組合，再把更早的符號經接收端尾端進來的影響也扣掉，得到對全部資料歷史成立的認證窗。

學習目標：(1) 寫出認證條件（式 9）並說明為什麼節點檢查能保證連續時間；(2) 求 AND4、MAJ4、XOR2 在 1、16、256 個葉盒下的認證窗與每側餘裕；(3) 用 de Bruijn 序列加上尾端項，把認證推廣到全部資料歷史；(4) 確認認證窗不大於同一盒的詳細模擬最小值。

② 原理與推導

1. 認證條件（草稿式 9）

取樣相位 tp（ps）是取樣時刻距符號起點的時間，0 ≤ tp < 2 UI。對每個取樣相位，取所有葉盒、所有符號中最差的「下界減護欄」：

m_(tp)=minℓmins[V_s(tp)−Γ¯s(tp)]−Ein−Ebtw Wcert=max{width(I):m_(tp)≥0∀tp∈I},每側餘裕=Wcert−Treq2

m̲（Pu）是認證 margin；Γ̄s(tp) 是符號 s 在該取樣相位的護欄上界（M4 s2），每個符號扣自己的護欄，與 M3 s3 的模擬同一算法；|Voff| 已含在 Γ̄ 內。Wcert（ps）是認證窗。為什麼只檢查節點就夠：節點上的 Γ̄ 已取相鄰兩格的較大者，Ebtw 涵蓋判讀量在兩節點之間偏離直線的量，所以相鄰兩個節點的 m̲ 都 ≥ 0 時，兩節點之間整格的任意時刻都安全。因此 Wcert 是連續時間的寬度（最長連續安全節點的終點減起點），不是格點估計。命題 1：若 Wcert ≥ Treq，盒內每一組延遲都有可用的取樣時刻；這是充分條件，不是必要條件。

延遲盒以對齊為中心、每路 ±r（r＝6.6 ps）。所有輸入一起平移的共同延遲會被取樣時刻吸收，把每組延遲減去 (max δi＋min δi)/2 後，任何跨距（最大延遲減最小延遲，含佈局本身的 skew）≤ 13.2 ps 的延遲組合都落在這個盒內。本步與 M3 s3 的共同窗一樣，要求同一個取樣時刻服務整個盒，包含共同平移的點，所以兩者可以直接比較。

2. 全部資料歷史

n 階 de Bruijn 序列 B(16, n) 是 16 種輸入狀態的循環序列，每一種長度 n 的符號組合恰好出現一次（n＝4 時 65,536 個符號）。取樣相位 tp < 2 UI − r 時，符號 s 的判讀量只受符號 s−(n−2) 到 s＋1 的完整影響，這 n 個符號的每一種組合都在序列裡，所以在序列上求的下界涵蓋它們。更早的符號只改變時刻 −(n−2)·UI＋trc＋r 之前的輸入（trc＝31.25 ps 是升餘弦邊緣全寬，r 涵蓋延遲），經接收端尾端影響判讀量：

|ΔV|≤(Dmax−Dmin)∑k≥⌊Th/Δ⌋|hk|,Th=tp+(n−2)UI−te−r

Dmax − Dmin（Pu）是 D 在所有包絡 x ∈ [0, 1]4 上的範圍，用 M4 s2 的區間法求（中心 0.5、半寬 0.5）；hk 是離散接收端脈衝響應，Th（ps）是較舊輸入到取樣時刻的最短距離。雜訊項同理：較舊各格的 S̄ 換成整個 [0, 1]4 的最大值 S̄max，σ̄2 加上 c2S̄maxΣKm（m 從 ⌊Th/Δ⌋ 再退 2 格起算，涵蓋護欄的包絡範圍與節點取大）。認證 margin 改為在 de Bruijn 序列上求 m̲，再扣 |ΔV| 並換用加大後的護欄。n 越大，Th 越長，尾端項越小，但序列長 16 倍。

全部資料歷史：B(16,4) 的尾端項在 AND4 的認證窗內最大 0.0041 Pu，只讓認證窗少 0.5 ps；B(16,3) 的尾端項大 20 倍（0.086 Pu），窗少 2 ps。de Bruijn 序列上 41 點的模擬窗與情境序列相同：在 41 點、0.5 ps 的解析度下，未見情境序列漏掉更差的符號組合；認證窗變窄主要來自尾端項。驗證 (c)：未加尾端項的下界 margin 在 de Bruijn 序列上每個取樣相位都低於 41 點的模擬 margin（最接近處仍低 0.002 Pu 以上）。

驗收：(a) 與草稿表 III 認證欄 31.5／32.5／37.5 ps 相差 −1.0／＋0.5／−0.5 ps（通過）；(b) 所有葉盒數與資料歷史的認證窗都 ≤ 同一序列的 41 點模擬最小值（通過）；(c) de Bruijn 序列上下界無違反（通過）；全部 ≥ Treq＝23 ps（通過）；葉盒越多窗越寬（通過）。

本步結論：(1) 在本模型下（升餘弦邊緣、固定延遲、相位已校準；護欄是 Q＝7 的機率性餘量，不是確定的上界），對整個 13.2 ps 盒、宣告的情境序列，單葉盒就認證了 AND4、MAJ4、XOR2 至少 30.5、33、37 ps 的共同取樣窗，每側餘裕 3.75–7 ps；對全部資料歷史（B(16,4) 加尾端項）為 30、31.5、37 ps，都大於 Treq＝23 ps。(2) 認證窗是保證值，比 41 點抽樣的最小值窄 6.5–16 ps；差距主要是單葉盒的一階項與餘項，切成 16 個葉盒（XOR2 4 個）後差距縮到 1.5–2 ps。(3) margin 的寫法要與模擬一致：每個符號扣自己的護欄；寫成兩個極值相減會讓 AND4、MAJ4 的認證窗少 4.5–5.5 ps，且看起來仍是「正確的下界」，只有與草稿或模擬對照才會發現。(4) 適用範圍：延遲是固定的通道延遲（不含每個位元都不同的抖動）；雜訊用 M3 s3 的 RIN 模型（不含 shot，也不是物理共光源 RIN 的上界，見 M4 s2 結論 (5)）；跨距大於 13.2 ps、macro 內部的差動延遲沒有在本步處理。

⑤ 常見錯誤與自我檢查

  • 下界與護欄分別取極值再相減：minsV̲s − maxsΓ̄s 仍是下界，但太保守；要 mins(V̲s − Γ̄s)。
  • 把格點數當窗寬：W 是安全區間的終點減起點；k 個連續安全節點的寬度是 (k−1)Δ。
  • 忘了連續時間誤差：節點上 m̲ ≥ 0 不代表節點之間安全，要先扣 Ein＋Ebtw。
  • 把情境序列的結果說成對所有資料都成立：只有 de Bruijn 序列加上尾端項，才涵蓋全部資料歷史。
  • 認證窗比抽樣結果寬：代表程式或推導有錯，不是「認證更準」。
自我檢查 1：AND4 單葉盒的認證窗 30.5 ps、41 點抽樣最小 37 ps、對齊 50 ps。這三個數字各自回答什麼問題？

對齊 50 ps：所有輸入延遲剛好相同時的窗。41 點 37 ps：盒內抽到的 41 組延遲中，最差那組的共同窗；沒抽到的延遲可能更差，所以它只是上限。認證 30.5 ps：盒內每一組延遲都至少有這麼寬，是下限。在情境序列、共同窗、本模型下，盒內真正的最小窗在 30.5 與 37 ps 之間。

自我檢查 2：為什麼 B(16,3) 的認證窗比 B(16,4) 窄，明明 B(16,3) 的序列短、組合少？

3 階序列只保證符號 s−1 到 s＋1 的組合都出現，更早的符號從距離取樣時刻較近的地方就開始算「未知」，Th 少 1 UI。接收端尾端在這段距離內還沒衰減完，尾端項大約大 20 倍（AND4 0.086 對 0.0041 Pu），扣掉後窗變窄。階數越高，未知的部分越遠、越小，但序列長度乘 16。
